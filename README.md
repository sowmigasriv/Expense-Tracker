# Expense-Tracker

A simple and user-friendly Expense Tracker Web Application built using HTML, CSS, and JavaScript. This application helps users track their income, expenses, and available balance in one place.

## Features

  Add Transactions: Add income and expense transactions easily.
  Balance Summary:View your total balance, income, and expenses.
  Transaction History:View all added transactions in a list.
  Delete Transactions:Remove individual transactions when needed.
  Reset Transactions:Clear all transaction records at once.
  Data Persistence:Transactions are saved using Local Storage, so data remains available even after refreshing the page.
  Responsive Design: Simple and clean interface for easy usage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Objective

The objective of this project is to develop a simple web application that helps users manage their income and expenses while practicing front-end web development concepts, DOM manipulation, event handling, and browser Local Storage

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a transaction description and amount.
5. Add positive amounts for income and negative amounts for expenses.
6. View your updated balance and transaction history.
